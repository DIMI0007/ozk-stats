# Установка OZK Stats 1.1.6

1. Закройте OBS Studio 33.
2. Распакуйте архив так, чтобы папка `stream-stats` оказалась в
   `C:\ProgramData\obs-studio\plugins\`. При обновлении замените файлы в ней.
   Файл `stream-stats.dll` должен лежать непосредственно в этой папке, рядом с `data`, если она есть.
3. Запустите OBS. Панель OZK Stats появится в меню **Док-панели** и по умолчанию
   откроется в нижней области. Её можно перетащить или изменить размер.

Панель предназначена для Windows x64 и OBS Studio 33. Архив содержит неподписанную
DLL без цифровой подписи. В панели доступны графики за 1/5/15 минут,
выбор языка и сводка текущего запуска OBS.

Если OBS показывает OZK Stats в разделе «Ошибки» и в журнале написано
`An Application Control policy has blocked this file`, файл заблокирован
Smart App Control Windows. Снятие отметки «Разблокировать» в свойствах архива
или DLL может не помочь. Не отключайте защиту ради проверки плагина:
для совместимости с этой политикой требуется выпуск с доверенной цифровой подписью.
